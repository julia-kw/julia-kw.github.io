    Section 5.5 Exercises

    Exercises Exercises

    1.

    Check an instance of the closure of the rational numbers by showing that \(\frac34 + \frac37\) can be written as a fraction of integers. Do the same for their product \(\frac 34 \cdot \frac 37\text{.}\)
    🔗
    🔗

    2.

    Check an instance of the closure of the rational numbers by showing that \(\frac23 - \frac54\) can be written as a fraction of integers. Do the same for their quotient \(\frac{2/3}{5/4}\text{.}\)
    🔗
    🔗

    3.

    If William Shakespeare were a mathematician, he might have written the following couplet for Ratio and Juliet: “What’s in a name? That which we call a fraction / By any other name would smell as sweet.” Check that \(\frac35\) would smell just as sweet if we called it \(\frac{72}{120}\) by showing that these two fractions name the same number.
    🔗
    🔗

    4.

    A student simplifies \(\frac{19}{95}\) by canceling out the \(9\)s to get \(\frac{1}{5}\text{.}\) They then simplify \(\frac{16}{64}\)by canceling out the \(6\)s to get \(\frac{1}{4}\text{.}\) Show that these two calculations happen to get the correct answer. Then show that this isn’t a valid method in general by showing that \(\frac{12}{26} \ne \frac{1}{6}\text{.}\)
    🔗
    🔗

    5.

    Check that the average of \(\frac34\) and \(\frac56\) is between them.
    🔗
    Hint.
    First compute the average using the formula \(\frac{x+y}{2}\text{.}\) Then convert everything to a common denominator to check the order.
    🔗
    🔗
    🔗
    Now that we have fractions we can make sense of negative exponents. Recall that positive exponents were defined as repeated multiplication: \(a^n\) is the product of \(a\) with itself \(n\) many times. Negatives, being the opposite of positives, should in the exponent have the opposite meaning of multiplication. That is, negative exponents represent repeated division. If \(-n\) is a negative number, then
    \begin{equation*} a^{-n} = \frac{1}{a^n}. \end{equation*}
    🔗

    6.

    Calculate \(2^{-3}\text{,}\) \(\left(\frac{1}{3}\right)^{-2}\text{,}\) and \(\left(\frac{3}{2}\right)^{-3}\text{.}\)
    🔗
    Hint 1.
    For the last two, it can be useful to think of it as \(a^{-n} = \left(\frac{1}{a}\right)^n\text{.}\) That is, think of it as taking a reciprocal then a positive power.
    🔗
    🔗
    Hint 2.
    When taking powers of fractions, a helpful rule is
    \begin{equation*} \left(\frac ab\right)^n = \frac{a^n}{b^n}. \end{equation*}
    🔗
    🔗
    🔗

    7.

    The usual rules for exponents still work given this definition of negative exponents. Check an instance of the rule \(a^m \cdot a^n = a^{m+n}\) by showing that
    \begin{equation*} \left(\frac35\right)^{-3} \cdot \left(\frac35\right)^2 = \left(\frac 35\right)^{-1}. \end{equation*}
    Show all steps of your calculations so that it is clear the calculations represented by each side really do give the same answer.
    🔗
    🔗

    8.

    Check an instance of the rule \((a^m)^n\) by showing that
    \begin{equation*} \left(\left(\frac{3}{2}\right)^{-2}\right)^{-2} = \left(\frac 32\right)^4. \end{equation*}
    Show all steps of your calculations so that it is clear the calculations represented by each side really do give the same answer.
    🔗
    🔗

    9.

    Each of the following values is given as a fraction, a percent, or a permille. For each of them, rewrite it into the other two forms. Please fully simplify all fractions.
    \begin{equation*} \frac35, \qquad 24\%, \qquad 720\text{‰} \end{equation*}
    🔗
    🔗

    10.

    Each year, an investment increases in value from its current value by \(10\%\text{.}\) How much has it increased from its initial value after two years? If it is initially worth \(10,000\) dollars, how much is it worth after two years?
    🔗
    Hint.
    The answer is not \(20\%\text{.}\)
