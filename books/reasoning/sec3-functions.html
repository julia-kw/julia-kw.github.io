    Section 3.1 Functions

    There is a pattern which repeats in many, many places where quantities are interesting and useful to us. We are interested not in a single quantity, but in how two quantities are related. As one quantity changes, so does the other. It is fruitful to think of one quantity as the independent variable whose changes determine what happens to the other quantity, the dependent variable.
    🔗
    The mathematical device to package this relationship is called a function. This is one of the most important and most general concepts in mathematics. We will look only at the case of functions which relate numbers. Recall that a real number is a number which expresses a quantity you can write as a decimal expansion of digits. That is, real numbers are always finite, can be positive or negative, and you can compare them as larger or smaller.
    🔗

    Definition 3.1.1. Functions of real numbers.

    A function is a way of associating a single output to each input. When talking abstractly it is common to give names like \(f,g\text{.}\) When working with an application often the name is chosen to stand for the quantity in the application. We write \(f(x)\) to refer to the output associated to the input \(x\text{.}\) When working with an application, we often pick a different variable for the input to stand for its meaning.
    🔗
    For our use, the inputs and outputs to functions will be real numbers. The domain of a function is the set of possible inputs and the range is the set of possible outputs.
    🔗
    Functions can be given in many ways. You might have a formula or equation which describes how to calculate the output \(f(x)\) knowing the input \(x\text{.}\) Or it might be given as an algorithm or process for computing outputs. Or it might be specified by pointing to some real world situation; outputs are associated with inputs but we don’t necessarily have a process or formula to specify how it’s done.
    🔗
    🔗
    A key detail in the definition is that a function assigns a single output to each input. While it is okay for multiple inputs to get sent to the same output, it is not allowed to send one input to multiple outputs.
    🔗

    Example 3.1.2.

    The conversion between temperature in Celsius versus Fahrenheit can be expressed as a function, given by a formula:
    \begin{equation*} F(t) = \frac95 t + 32. \end{equation*}
    Here, \(t\) is a temperature in Celsius and \(F(t)\) is the corresponding temperature in Fahrenheit.
    • \(F(0) = 32\) expresses that \(0^\circ\) Celsius, the freezing point of water, is \(32^\circ\) Fahrenheit.
      🔗
      🔗
    • \(F(100) = 212\) expresses that \(100^\circ\) C, the boiling point of water, is \(212^\circ\) F.
      🔗
      🔗
    • \(F(-40) = -40\) expresses that \(-40^\circ\) is where both scales give the same number for the temperature.
      🔗
      🔗
    🔗
    🔗

    Example 3.1.3.

    The height of an object dropped from a height of \(160\) meters can be modeled with a function. The input \(t\) is the time in, say, seconds after the object was dropped. And the output \(h(t)\) is the height above the ground, say in meters, of the object at that time. Making some simplifying assumptions, we can describe this function by a formula which approximates the real association.
    \begin{equation*} h(t) = 160 - 10t^2 \end{equation*}
    Explaining where this formula comes from requires some work in physics. Briefly, \(10\) meters per square second represents the acceleration due to gravity, which is the only force acting to change the object’s position.
    🔗
    That the initial height of the object is \(100\) meters is represented by the fact that \(h(0) = 100\text{.}\) That the object hits the ground after \(4\) seconds is represented by the fact that \(h(4) = 0\text{.}\)
    🔗
    🔗
    Note that in this second example, the formula only approximates the function associating heights to moments of time. The simplified formula ignores considerations like air resistance, and thereby gives slightly inaccurate values. This is typical for applications of mathematics. We get a good enough or close enough picture. If it’s not actually good enough we can search for a better, probably more complicated model.
    🔗
    A convenient fact about functions is that there is a uniform process for visualizing them. This is done using Cartesian coordinates. Points in two-dimensional space are represented with pairs of coordinates \((x,y)\text{.}\) The \(x\)-coordinate specifies the horizontal position of a point and the \(y\)coordinate specifies the vertical position. The graph of a function \(f\) is the curve formed by looking at all points \((x,f(x))\) of input-output pairs.
    🔗
    
    A graph of the function \(f(x) = \sqrt x\text{.}\) Takes the form of the top half of a parabola opening to the right.
    🔗
    Visualizing a function via its graph, as in the above graph of the function \(f(x) = \sqrt x\text{,}\) can let you get important information quickly.
    🔗

    Definition 3.1.4.

    Throughout consider a function \(f\text{.}\)
    • \(f\) is increasing somewhere if the output increases as the input increases. Graphically, this means the slope or instantaneous rate of change is positive.
      🔗
      🔗
    • \(f\) is decreasing somewhere if the output decreases as the input increases. Graphically, this means the slope is negative.
      🔗
      🔗
    • \(f\) is constant somewhere if the output stays constant, neither increasing nor decreasing, as the input changes. Graphically, this means the graph is locally a horizontal line.
      🔗
      🔗
    • \(f\) has a local maximum at an input \(x_0\) if the output of the function is larger than nearby points. That is, \(f(x) \gt f(x_0)\) for sufficiently close inputs \(x\text{.}\)
      🔗
      🔗
    • \(f\) has a local minimum at an input \(x_0\) if the output of the function is smaller than nearby points. That is, \(f(x) \lt f(x_0)\) for sufficiently close inputs \(x\text{.}\)
      🔗
      🔗
    • \(f\) is concave up somewhere if the function bends upward. Graphically, this means if you draw a line between two points on the graph the line sits above the graph. You can also understand this in terms of rates of change; it means that the slope is increasing as the input increases.
      🔗
      🔗
    • \(f\) is concave down somewhere if the function bends downward. Graphically, this means if you draw a line between two points on the graph the line sits below the graph. You can also understand this in terms of rates of change; it means that the slope is decreasing as the input increases.
      🔗
      🔗
    • \(f\) has an inflection point at an input if the concavity changes there, from concave up to concave down or vice versa.
      🔗
      🔗
    🔗
    🔗
