    Section 3.3 Exponential functions

    Last section we looked at linear models. These are useful for many things, but they are based on the assumption that the rate of change is constant, or at least is approximately constant. Sometimes this assumption doesn’t hold. For example, suppose you want to model algae growth in a pond. How fast the area of algae is growing won’t be constant; if there is more algae that is more algae to grow so the total amount will grow even faster.
    🔗
    When dealing with phenomena like this, where the rate of change is proportional to the size, we need a different tool. In this section we discuss that tool.
    🔗

    Definition 3.3.1. Exponentiation.

    Suppose that \(a\) is a number and \(x\) is another number. We define the exponential \(a^x\) based on the kind of number the exponent \(x\) is. For some of these, they only make sense when \(a\) is non-negative.
    • If the exponent is a positive whole number \(x\) then \(a^x\) is \(x\) many \(a\)s multiplied together:
      \begin{equation*} a^x = \underbrace{a \cdot a \cdot a \cdots a}_{x \text{ many}}. \end{equation*}
      🔗
      🔗
    • If \(x = 0\) then \(a^x = 1\text{.}\)
      🔗
      🔗
    • If the exponent is a reciprocal of a positive integer \(1/d\) we take a root:
      \begin{equation*} a^{1/d} = \sqrt[d]{a}. \end{equation*}
      This might not make sense if \(a\) is negative.
      🔗
      🔗
    • If the exponent is a fraction of integers \(n/d\) we combine the previous rules:
      \begin{equation*} a^{n/d} = \sqrt[d]{a^n}. \end{equation*}
      Again, this might not make sense if \(a\) is negative.
      🔗
      🔗
    • If the exponent is negative we divide instead of multiply:
      \begin{equation*} a^{-x} = \frac{1}{a^x}. \end{equation*}
      🔗
      🔗
    🔗
    Left unsaid is what we do if the exponent \(x\) is an irrational number, such as \(\pi\) or \(\sqrt 2\text{.}\) That case can be handled, but it takes ideas from calculus. So for our purposes we will sweep that under the table. I just want to highlight that for this case, it only makes sense when \(a\) is non-negative; we can’t get a sensible real number value for, say, \((-2)^\pi\text{.}\)
    🔗
    🔗
    The following properties are key to the use of exponentials. You can check by counting that they hold for positive integer exponents. You can think of expanding the definition of exponentiation to more exponents as expanding the domain while keeping these important properties; if you want these properties to continue to hold this is the only way to expand the definitions.
    🔗

    Theorem 3.3.2. Properties of exponentiation.

    The following are true for any bases \(a,b\) and any exponents \(x,y\text{.}\)
    • \(\displaystyle \displaystyle a^{x + y} = a^x \cdot a^y \)
      🔗
      🔗
    • \(\displaystyle \displaystyle a^{x - y} = \frac{a^x}{a^y}\)
      🔗
      🔗
    • \(\displaystyle \displaystyle a^{xy} = \left(a^x\right)^y\)
      🔗
      🔗
    • \(\displaystyle \displaystyle (ab)^x = a^x \cdot b^x\)
      🔗
      🔗
    🔗
    🔗

    Definition 3.3.3. Exponential functions.

    An exponential function is one of the form
    \begin{equation*} f(x) = a^x, \end{equation*}
    where the base \(a\) is positive and not equal to \(1\text{.}\)
    🔗
    Here any number \(x\) makes sense for an input, so the domain is the entire real line.
    🔗
    🔗
    The reason to require the base to be non-negative is because \(a^x\) doesn’t make sense for most exponents \(x\) when \(a\) is negative. The reason to require the base to be neither zero nor one is that those are boring. Zero to any power is zero and one to any power is one.
    🔗
    A nice fact about exponential functions is that their graphs all look similar. More precisely, there are two possible shapes, based on whether the base is \(\gt 1\) or \(\lt 1\text{.}\) And these two shapes are mirror images of each other.
    🔗
    
    Two exponential functions. The one on the left has a base \(\gt 1\) and the one on the right has a base \(\lt 1\text{.}\)
    🔗
    Of course, the base has an effect on the shape. A larger base will give a steeper graph, that is a function which changes more rapidly. Think of how powers of \(3\text{,}\) namely \(3, 9, 27, 81, 243, 729, \ldots\text{,}\) grow more quickly than powers of \(2\text{,}\) namely \(2, 4, 8, 16, 32, 64\text{.}\) The growth rates may different, but the basic shape is the same.
    🔗
    Let’s explore more closely some important features of that shape. Our main focus will be on when the base is \(\gt 1\text{;}\) for the base \(\lt 1\) case we flip everything sideways.
    🔗
    Let’s start with something basic. The initial value of \(a^x\text{,}\) the value it has at \(x = 0\) is always \(1\text{.}\) In the next section when we look at exponential models we will see that if you want to model something with an initial value of \(P_0\) it’s as easy as multiplying the exponential by \(P_0\text{.}\)
    🔗
    An important feature to notice is what happens as the input \(x\) increases to infinity. As the input increases, \(a^x\) blows up very fast. This is a striking feature of exponential functions. If you graph, for instance, \(2^x\) and \(x^2\) on the same graph you will see that the exponential grows much faster. Indeed, if you graph \(a^x\) for any base \(a \gt 1\text{,}\) no matter how small, on the same axes as \(x^n\) for any value of \(n\text{,}\) if you zoom out enough you will see that eventually the exponential grows much faster.
    🔗

    Example 3.3.4.

    You win an international chess tournament and are awarded prize money. You are given two options for your prize. The first is that you will be given a million dollars immediately. The second is that you will get a chess piece and one dollar. A week later you will get another chess piece and two dollars. This will continue each week with a new chess piece and double the previous week’s money until you’ve received all thirty-two chess pieces. Which option should you pick?
    🔗
    The payout of the first option is easy to calculate. It’s one million. The second option requires some work. On week \(n\) you get \(2^{n-1}\) dollars. (It’s \(n-1\) and not \(n\) because it starts at \(1 = 2^0\) dollars.) This means on week \(32\) you will receive
    \begin{equation*} 2^{31} = 2,147,483,648 \approx \text{two billion dollars}. \end{equation*}
    Unless you absolutely need a million dollars tomorrow, the second option is by far the better one.
    🔗
    🔗
    If we look at what happens as the input \(x\) decreases to \(-\infty\) we see an opposite behavior. Instead of getting larger and larger, \(a^x\) gets smaller and smaller, getting closer and closer to \(0\text{.}\) It will never actually equal \(0\text{,}\) but it will get arbitrarily close.
    🔗
    When we look at modeling, this behavior will be useful for modeling quantities that asymptotically decrease down to zero.
    🔗
    We’ve saved for last the essential property of exponential functions, the one that explains why they are so helpful for modeling. Namely, this property has to do with the rate of change of exponentials.
    🔗
    For linear functions, their rate of change was given by their slopes. With lines we have a straightforward method to calculate slope, namely the “rise over run” fraction. For other functions whose graphs are curves, it is not so easy to calculate rates of change. Indeed, this is so difficult a problem that it took Leibniz and Newton inventing calculus to solve this problem.
    🔗
    We won’t learn how to calculate general rates of change—we’d need calculus for that. But we can get an idea of what it means. If you take a graph of a function and zoom in, such as on a graphing calculator, then eventually the graph starts to look like a line. This line, called the tangent line has a slope. That slope is the rate of change of the function at that input.
    🔗
    For linear functions, the entire graph is a line and so has the same slope and the same rate of change. For other functions, the rate of change itself changes across different inputs. Think, for example, of a graph representing the speed of a train during your commute. The rate of change in this context is the acceleration of the train. Sometimes this rate of change is zero, when the train is up to speed and not changing. Other times this rate of change is positive; when the train takes off from a stop it needs to speed up. Yet other times this rate of change is negative; the train needs to slow down to approach a stop.
    🔗
    While it takes sophisticated technology to precisely quantify rates of change, there is a nice visual meaning for positive versus zero versus negative rate of change.
    • The rate of change being positive means the function is increasing; the graph moves up as you move to the right.
      🔗
      🔗
    • The rate of change being negative means the function is decreasing; the graph moves down as you move to the right.
      🔗
      🔗
    • The rate of change being zero means the function is neither increasing nor decreasing. This might be because the function is constant for a time, or it might be at a moment where the function changes between increasing and decreasing.
      🔗
      🔗
    🔗
    Exponential functions are useful and interesting because they are the functions whose rate of change is always proportional to the current value. Stated precisely, suppose that \(f(x)\) is a function whose rate of change at an input \(x_0\) is always \(K \cdot f(x_0)\) for a fixed number \(K\text{.}\) Then, \(f(x)\) is of the form
    \begin{equation*} f(x) = C \cdot a^x, \end{equation*}
    for some base \(a\) and some initial value \(C\text{.}\) This property is why exponential models are so common.
    🔗
    As a coda, let me mention the most common base one sees for exponential functions in applications. This base, which is written as \(e\) can be thought of as similar to \(\pi\text{.}\) It is an irrational number—so its decimal expansion goes forever without repeating, and it can’t be written as a fraction of whole numbers. It doesn’t admit a simple formula defining it, and the best we can do is give it a letter as a name.
    \begin{equation*} e \approx 2.718281828459. \end{equation*}
    The importance of base \(e\) can be explained by citing a fact from calculus. As said above, exponential functions are important because they are those functions whose rate of change is proportional to their size. The rate of change of the exponential \(a^x\) at an input \(x_0\) is \(K \cdot a^{x_0}\text{,}\) where \(K\) is a constant which depends on the base \(a\text{.}\) The base \(e\) is the unique base where this constant \(K = 1\text{.}\) That is, the rate of change of \(e^x\) is \(e^x\) itself.
    🔗
    This fact makes it convenient to use base \(e\) for calculations, and this is what is commonly done.
    🔗
